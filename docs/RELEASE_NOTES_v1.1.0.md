## Annoying Client 1.1.0 (Minecraft 1.21.11)

**Download [`AnnoyingClient-1.1.0-Windows.zip`](https://github.com/theavgjim/annoying-client/raw/main/docs/download/AnnoyingClient-Windows.zip)**, extract it, and run `AnnoyingClient.exe`.

- **Launcher:** installs Minecraft 1.21.11, Fabric 0.20.1, Java 21 and Annoying Client, then plays through the official Minecraft Launcher.
- **Mods:** browse and install Fabric mods from Modrinth, with dependencies, updates and enable/disable.
- **Performance:** Max FPS / Balanced / Quality presets, one-click Sodium, Lithium, FerriteCore, Entity Culling and ImmediatelyFast, memory and GC tuning.
- **New in 1.1.0:** launcher profiles with a "1.21.11 optimized" 50-mod template, a Mod Configs tab, and a Wardrobe with capes, trails and coins.
- **In game:** ClickGUI (Right Shift), 9 HUD elements with a drag-and-drop editor, 5 themes, profiles, zoom, fullbright, custom crosshair.

Windows may show "Windows protected your PC" because the app is not code-signed: click **More info > Run anyway**.
